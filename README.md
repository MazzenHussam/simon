# 🎮 Simon Game

**Simon Game** is a classic browser game inspired by the popular electronic memory game. It challenges players to repeat a growing sequence of colors and sounds. Developed using pure HTML, CSS, and JavaScript.

---

## 🚀 Features

- Four colored buttons: red, green, blue, yellow  
- Each round adds a new random color to the sequence  
- Player must repeat the sequence by clicking buttons  
- Game tracks and displays current round  
- Sound effects for each button  
- Visual feedback when a button is pressed  
- Game over when the player makes a mistake  
- Responsive design — works on desktop and mobile

---

## 🛠 Built With

- **HTML5** for structure  
- **CSS3** for styling and animations  
- **JavaScript (ES6)** for game logic and user interaction
